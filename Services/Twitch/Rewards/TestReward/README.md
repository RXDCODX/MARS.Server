# TestReward - Тестовая награда для проверки перехвата активации

## Описание

Тестовая награда предназначена для проверки работы системы перехвата активации наград из DI, которые реализуют `ChannelRewardDefinition`.

## Характеристики награды

- **Название**: "Тестовая награда"
- **Стоимость**: 88888 баллов
- **Цвет**: #FF6B6B (красный)
- **Требует ввод пользователя**: Да
- **Подсказка**: "Введите 'test' для тестирования отмены награды"

## Логика работы

### Перехват активации

Сервис `TestRewardService` перехватывает активацию награды через событие `ChannelPointsCustomRewardRedemptionAdd` и проверяет:

1. **Активен ли сервис** (`IsServiceActive`)
2. **Правильная ли стоимость** (88888 баллов)
3. **Правильный ли канал** (сравнение с `TwitchExstension.Channel`)

### Обработка пользовательского ввода

- **Если ввод содержит "test"** (в любом регистре или транскрипции):
  - Награда **отменяется** (`CANCELED`)
  - Пользователю отправляется сообщение об отмене
  - Логируется информация о перехвате

- **Если ввод НЕ содержит "test"**:
  - Награда **выполняется** (`FULFILLED`)
  - Пользователю отправляется сообщение о выполнении
  - Логируется информация о выполнении

### Поддерживаемые варианты текста "test"

- `test`, `TEST`, `Test`
- `тест`, `Тест`, `ТЕСТ`

## Регистрация в DI

Сервис зарегистрирован в `StartupEstensions.cs`:

```csharp
services.AddSingleton<TestRewardService>();
services.AddHostedService(sp => sp.GetRequiredService<TestRewardService>());
```

## Использование

1. Запустите приложение
2. Создайте награду в Twitch с ценой 88888 баллов
3. Активируйте награду с текстом "test" - она будет отменена
4. Активируйте награду с любым другим текстом - она будет выполнена

## Логирование

Все действия логируются с уровнем `Information`:

- Перехват награды
- Отмена/выполнение награды
- Ошибки при обработке

## Тестирование

Эта награда позволяет проверить:

- Корректность перехвата наград из DI
- Работу системы отмены выполнения наград
- Обработку пользовательского ввода
- Интеграцию с Twitch API
