# Twitch Message Builder Service

Сервис для создания и управления автоматическими ответами на сообщения в чате Twitch с поддержкой переменных и настройки автора.

## Возможности

- **Шаблоны сообщений** - создание шаблонов с переменными
- **Триггер-слова** - активация ответов по ключевым словам
- **Переменные** - поддержка {user}, {displayName}, {username}
- **Настройка автора** - указание имени и цвета автора сообщения
- **Приоритеты** - настройка порядка срабатывания шаблонов
- **Случайность** - настройка вероятности срабатывания (0-100%)
- **Кулдаун** - ограничение частоты срабатывания
- **Статистика** - отслеживание использования шаблонов

## Переменные в шаблонах

- `{user}` - никнейм пользователя (username)
- `{displayName}` - отображаемое имя пользователя
- `{username}` - синоним для {user}

## Примеры шаблонов

### Простое приветствие
```
Название: Приветствие
Триггер: привет
Шаблон: Привет, {user}! Рад тебя видеть!
```

### Ответ с цветным автором
```
Название: Команда помощи
Триггер: помощь
Шаблон: {user}, вот список доступных команд: !help, !info, !stats
Цвет автора: #FF0000
Имя автора: Бот
```

### Случайный ответ
```
Название: Случайная шутка
Триггер: шутка
Шаблон: {user}, вот шутка для тебя: {randomJoke}
Случайность: 30
Кулдаун: 300
```

## API Endpoints

### Получить все шаблоны
```
GET /api/twitch/message-templates
```

### Получить шаблон по ID
```
GET /api/twitch/message-templates/{id}
```

### Создать шаблон
```
POST /api/twitch/message-templates
Content-Type: application/json

{
  "name": "Название шаблона",
  "messageTemplate": "Привет, {user}!",
  "description": "Описание шаблона",
  "triggerWord": "привет",
  "authorColor": "#FF0000",
  "authorName": "Бот",
  "priority": 1,
  "randomChance": 100,
  "cooldownSeconds": 0
}
```

### Обновить шаблон
```
PUT /api/twitch/message-templates/{id}
Content-Type: application/json

{
  "messageTemplate": "Новый текст сообщения",
  "priority": 2
}
```

### Удалить шаблон
```
DELETE /api/twitch/message-templates/{id}
```

### Получить шаблоны по триггеру
```
GET /api/twitch/message-templates/by-trigger/{triggerWord}
```

### Получить активные шаблоны
```
GET /api/twitch/message-templates/active
```

### Получить статистику
```
GET /api/twitch/message-templates/stats
```

## Настройка приоритетов

Приоритеты работают по принципу "чем выше число, тем выше приоритет":

- **0** - базовый приоритет
- **1-10** - низкий приоритет
- **11-50** - средний приоритет
- **51-100** - высокий приоритет

При одинаковом приоритете выбирается более старый шаблон.

## Настройка случайности

- **0%** - шаблон никогда не срабатывает
- **1-99%** - шаблон срабатывает с указанной вероятностью
- **100%** - шаблон срабатывает всегда (по умолчанию)

## Кулдаун

Кулдаун задается в секундах и определяет минимальный интервал между срабатываниями одного шаблона:

- **0** - без ограничений
- **60** - не чаще раза в минуту
- **300** - не чаще раза в 5 минут
- **3600** - не чаще раза в час

## Цвета автора

Цвета указываются в формате HEX (#RRGGBB):

- **#FF0000** - красный
- **#00FF00** - зеленый
- **#0000FF** - синий
- **#FFFF00** - желтый
- **#FF00FF** - пурпурный
- **#00FFFF** - голубой

## Логирование

Сервис ведет подробные логи:
- Создание/обновление/удаление шаблонов
- Срабатывание шаблонов
- Ошибки обработки сообщений
- Статистика использования

## Интеграция с OBS

Сообщения отправляются через SignalR хаб `TelegramusHub` с методом `TemplateMessage`, что позволяет отображать их в OBS.

## Мониторинг

Сервис автоматически:
- Загружает активные шаблоны при запуске
- Обновляет кэш каждые 5 минут
- Отслеживает статистику использования
- Проверяет кулдауны и случайность

## Безопасность

- Валидация входных данных
- Ограничение длины полей
- Защита от SQL-инъекций через Entity Framework
- Логирование всех операций
