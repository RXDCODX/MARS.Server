# Changelog - RxdcodxViewersService

## Версия 3.0.0 - Database-First Cache Architecture

### ✨ Новые возможности

#### Database-First Cache

- **База данных как кеш** - убран `ConcurrentDictionary`, БД используется как основное хранилище
- **Персистентность данных** - данные сохраняются между перезапусками приложения
- **Упрощенная архитектура** - нет необходимости в синхронизации между кешем и БД
- **Автоматическое восстановление** - при запуске сервис загружает данные из БД

#### FollowerInfo Entity

- **Расширенная модель данных** `FollowerInfo` для работы с фоловерами
- **Дополнительные поля**:
  - `LastUpdated` - время последнего обновления
  - Методы для проверки актуальности данных
- **Совместимость** с `ChannelFollower` через методы преобразования
- **Оптимизированные методы** - улучшенная производительность

#### Новые методы API

- `GetAllFollowersInfo()` - получение фоловеров как `FollowerInfo`
- `GetFollowerInfo(userId)` - информация о конкретном фоловере
- `ClearFollowersCache()` - очистка БД (асинхронный)
