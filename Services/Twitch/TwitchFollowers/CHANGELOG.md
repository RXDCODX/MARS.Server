# Changelog - RxdcodxViewersService

## Версия 2.0.0 - Concurrent Collections & FollowerInfo Entity

### ✨ Новые возможности

#### FollowerInfo Entity

- **Новая модель данных** `FollowerInfo` для расширенной работы с фоловерами
- **Дополнительные поля**:
  - `LastUpdated` - время последнего обновления
  - Методы для проверки актуальности данных
- **Совместимость** с `ChannelFollower` через методы преобразования
- **Потокобезопасность** - оптимизированные методы сравнения

#### Concurrent Collections

- **ConcurrentDictionary** вместо обычного `List` с `lock`
- **Улучшенная производительность** - нет блокировок при чтении
- **Потокобезопасность** - безопасная работа в многопоточной среде

#### Новые методы API

- `GetAllFollowersInfo()` - получение фоловеров как `FollowerInfo`
- `GetFollowerInfo(userId)` - информация о конкретном фоловере
- `GetCachedFollowersCount()` - количество фоловеров в кеше
- `ClearFollowersCache()` - очистка кеша
