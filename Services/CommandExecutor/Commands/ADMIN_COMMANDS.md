# Админские команды MARS.Server

## Обзор
Админские команды требуют специальных привилегий для выполнения и предназначены для управления системой, настройки параметров и выполнения административных задач.

## Список админских команд

### 🖥️ Системные команды
- **systeminfo** - Показывает информацию о системе и сервисах
- **directory** - Показывает структуру директорий сервера
- **scrupframedata** - Запускает парсинг фреймдаты Tekken 8 с сайта

### 🔊 Управление TTS
- **ttsvolume** - Устанавливает или показывает текущую громкость TTS
- **ttsstop** - Останавливает все текущие TTS-фразы

### 🎮 Управление игровыми событиями
- **fumo** - Объявляет Fumo Friday для пользователя
- **randommem** - Управление случайными мемами
- **waifuunmerge** - Управление вайфу (объединение/разделение)
- **rollwaifu** - Выполняет вайфу-ролл для пользователя
- **hellovideo** - Отправляет приветственное видео пользователю

### 📺 Управление Twitch
- **twitchevents** - Управление событиями Twitch
- **twitchsubrec** - Управление подписками Twitch
- **joinedtwitchchannels** - Показывает список подключенных Twitch каналов
- **catisa** - Отправляет сообщение на Twitch канал

### 📋 Информационные команды
- **whitelist** - Показывает список пользователей с доступом к PyroAlerts
- **commands** - Показывает список всех доступных команд бота
- **honkaiusers** - Показывает список пользователей с уведомлениями Honkai

### 🧪 Тестовые команды
- **example** - Пример команды с несколькими параметрами
- **platformtest** - Тестовая команда для демонстрации работы с платформами
- **discord** - Команда для Discord

### 🎯 Специальные команды
- **tanya** - Показывает ближайший рабочий день Тани

## Обоснование админского статуса

### Команды, требующие админских прав:

1. **systeminfo** - Доступ к системной информации может быть чувствительным
2. **directory** - Информация о структуре файловой системы сервера
3. **scrupframedata** - Запуск ресурсоемких процессов парсинга
4. **ttsvolume** - Изменение системных настроек звука
5. **ttsstop** - Принудительная остановка системных процессов
6. **fumo** - Управление событиями на стриме
7. **randommem** - Управление контентом
8. **waifuunmerge** - Управление игровыми данными
9. **rollwaifu** - Управление игровыми функциями
10. **hellovideo** - Управление медиаконтентом
11. **twitchevents** - Управление интеграцией с Twitch
12. **twitchsubrec** - Управление подписками
13. **joinedtwitchchannels** - Информация о подключениях к Twitch
14. **catisa** - Отправка сообщений в Twitch
15. **whitelist** - Доступ к списку пользователей с привилегиями
16. **commands** - Полный список команд системы
17. **honkaiusers** - Информация о пользователях с уведомлениями
18. **example** - Тестовая команда для разработки
19. **platformtest** - Тестирование платформ
20. **discord** - Команда для Discord интеграции
21. **tanya** - Специальная команда для администраторов

### Команды, НЕ требующие админских прав:

- Информационные команды (help, links)
- Развлекательные команды (byebye)
- Команды для получения данных (framedata, honkai, genshin, zonezero)
- Команды для просмотра информации (start, telegramonly)

## Безопасность

Все админские команды должны выполняться только авторизованными администраторами. Система проверяет права доступа перед выполнением таких команд.

## Добавление новых админских команд

При создании новой команды учитывайте:
1. Требует ли команда доступа к системным ресурсам?
2. Может ли команда изменить настройки системы?
3. Управляет ли команда контентом или событиями?
4. Требует ли команда специальных привилегий?

Если ответ "да" на любой из вопросов - команда должна быть помечена как админская.
