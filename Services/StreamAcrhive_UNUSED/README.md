# Stream Archive Service

Сервис для автоматического архивирования потоков в Telegram каналы.

## Описание

Сервис периодически проверяет указанные папки на наличие новых видеофайлов, разбивает большие файлы на части до 2ГБ и загружает их в Telegram каналы через WTelegram.

## Возможности

- ✅ Периодическая проверка папок на новые файлы
- ✅ Автоматическая разбивка файлов больше 2ГБ на части с помощью FFmpeg
- ✅ Загрузка в Telegram каналы через WTelegram
- ✅ Поддержка различных видеоформатов (MP4, AVI, MKV, MOV, WMV, FLV, WebM, M4V, 3GP)
- ✅ Настраиваемые форматы имен файлов
- ✅ Гибкие интервалы проверки
- ✅ REST API для управления конфигурациями
- ✅ Полное отслеживание файлов в базе данных
- ✅ Статистика загрузок и обработки файлов
- ✅ Отслеживание статуса каждой части файла
- ✅ Интеграция с FFmpeg для качественной разбивки видео

## Настройка

### 1. Добавление конфигурации через API

```http
POST /api/StreamArchive
Content-Type: application/json

{
  "telegramChannelId": -1001234567890,
  "fileNameFormat": "stream_{date}_{original}",
  "checkSpan": "00:05:00",
  "folderPath": "C:\\Streams\\Archive",
  "isConvertFile": false,
  "fileConvertType": 0
}
```

### 2. Параметры конфигурации

| Параметр | Тип | Описание |
|----------|-----|----------|
| `telegramChannelId` | ulong | ID Telegram канала для загрузки |
| `fileNameFormat` | string | Формат имени файла (поддерживает плейсхолдеры) |
| `checkSpan` | TimeSpan | Интервал проверки папки |
| `folderPath` | string | Путь к папке с файлами для архивирования |
| `isConvertFile` | bool | Флаг конвертации файлов (пока не реализовано) |
| `fileConvertType` | StreamArchiveVideoFormats | Тип конвертации |

### 3. Плейсхолдеры для имен файлов

| Плейсхолдер | Описание | Пример |
|-------------|----------|--------|
| `{date}` | Текущая дата | 2025-01-15 |
| `{time}` | Текущее время | 14-30-25 |
| `{datetime}` | Дата и время | 2025-01-15_14-30-25 |
| `{original}` | Оригинальное имя файла | stream_20250115_143000 |
| `{timestamp}` | Unix timestamp | 1705316425 |

## Требования

### FFmpeg

Сервис использует FFmpeg для разбивки больших видеофайлов. Убедитесь, что FFmpeg установлен и доступен в системе:

**Windows:**

- Скачайте FFmpeg с официального сайта
- Добавьте путь к `ffmpeg.exe` и `ffprobe.exe` в переменную PATH
- Или разместите в стандартных папках: `C:\ffmpeg\bin\`

**Linux/macOS:**

```bash
# Ubuntu/Debian
sudo apt install ffmpeg

# macOS
brew install ffmpeg
```

Сервис автоматически найдет FFmpeg в системе или выведет предупреждение в логах.

## Ограничения

- Максимальный размер файла для загрузки в Telegram: 2ГБ
- Поддерживаются только видеофайлы
- Файлы удаляются после успешной загрузки
- Требуется настройка WTelegram для работы с Telegram API
- Требуется установленный FFmpeg для разбивки больших файлов

## База данных

Сервис создает следующие таблицы для отслеживания файлов:

### StreamArchiveConfigs

Хранит конфигурации архивирования

### StreamArchiveFiles  

Отслеживает каждый обработанный файл:

- Оригинальные и обработанные имена файлов
- Размеры и пути
- Статусы обработки (Discovered, Processing, Completed, Failed, Skipped)
- Временные метки
- ID сообщений в Telegram
- Связь с частями файла

### StreamArchiveFileChunks

Отслеживает каждую часть разбитого файла:

- Номер части и общее количество
- Размеры и смещения
- Статусы загрузки (Created, Uploading, Uploaded, Failed)
- ID сообщений в Telegram для каждой части

## Безопасность

- Все операции с файлами выполняются в контексте приложения
- Временные файлы автоматически удаляются
- Валидация путей к папкам
- Проверка существования каналов перед загрузкой
- Полное логирование всех операций

## Устранение неполадок

### Файлы не загружаются

1. Проверьте права доступа к папке
2. Убедитесь, что WTelegram настроен корректно
3. Проверьте ID канала в Telegram
4. Проверьте логи на наличие ошибок

### Большие файлы не разбиваются

1. Убедитесь, что достаточно места на диске для временных файлов
2. Проверьте права на запись в папку Temp

### Сервис не запускается

1. Проверьте конфигурацию базы данных
2. Убедитесь, что выполнены миграции
3. Проверьте логи приложения
