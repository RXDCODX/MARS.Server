# Keyboard Hook Service

Сервис для перехвата нажатия клавиш на клавиатуре с использованием библиотеки [H.Hooks](https://github.com/HavenDV/H.Hooks).

## Описание

Сервис отслеживает одновременное нажатие клавиш "A" и "Numpad 9" или "A" и "P", и при обнаружении такой комбинации вызывает метод `LeroyAlert()` в SignalR хабе `TelegramusHub`.

## Функциональность

- Глобальный перехват клавиатуры (работает даже когда приложение не в фокусе)
- Отслеживание комбинаций клавиш:
  - `A` + `Numpad 9`
  - `A` + `P`
- Автоматический вызов SignalR метода при обнаружении комбинации
- Логирование всех событий
- Безопасная остановка и очистка ресурсов

## Установка

1. Добавьте пакет H.Hooks в проект:

```bash
dotnet add package H.Hooks
```

2. Зарегистрируйте сервис в `Program.cs` или `Startup.cs`:

```csharp
using MARS.Server.Services.KeyboardHook;

// В методе ConfigureServices
services.AddKeyboardHookService();
```

## Использование

Сервис автоматически запускается при старте приложения и работает в фоновом режиме. При нажатии комбинации клавиш `A` + `Numpad 9` или `A` + `P` автоматически вызывается метод `LeroyAlert()` в хабе.

## Конфигурация

Сервис не требует дополнительной конфигурации и работает "из коробки".

## Требования

- .NET 6.0 или выше
- Windows (для полной функциональности)
- Библиотека H.Hooks (только на Windows)
- На не-Windows платформах автоматически используется заглушка

## Безопасность

- Сервис использует низкоуровневые хуки Windows
- Все операции выполняются в безопасном контексте
- Корректная очистка ресурсов при остановке

## Логирование

Сервис логирует все важные события:

- Запуск и остановка
- Обнаружение комбинаций клавиш
- Вызовы SignalR методов
- Ошибки и исключения

## Примеры

### Проверка статуса сервиса

```csharp
public class SomeController : ControllerBase
{
    private readonly IKeyboardHookService _keyboardHookService;
    
    public SomeController(IKeyboardHookService keyboardHookService)
    {
        _keyboardHookService = keyboardHookService;
    }
    
    [HttpGet("keyboard-status")]
    public IActionResult GetKeyboardStatus()
    {
        return Ok(new { IsActive = _keyboardHookService.IsActive });
    }
}
```

## Примечания

- **Windows**: Полная функциональность с использованием библиотеки H.Hooks
- **Не-Windows платформы**: Автоматически используется заглушка для совместимости
- Требует права администратора на Windows для глобального перехвата клавиатуры
- Рекомендуется использовать только в доверенных средах
- Сервис автоматически адаптируется к платформе при регистрации
